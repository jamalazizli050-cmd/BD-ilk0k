# ЛЕХА · 16

Одностраничный праздничный сайт-открытка ко дню рождения (26.08.2010 → 16 лет).
Vite + React, чистый CSS/CSS-модули, анимации на framer-motion и CSS.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
```

## Фото

Клади файлы в `public/images/`:

| файл | где используется |
|---|---|
| `photo1.jpg` … `photo4.jpg` | фотогалерея |
| `lekha.jpg` | тизер подарка |
| `keyboard.jpg` | финальная карточка с подарком |

Пока файла нет — на его месте аккуратный плейсхолдер, сайт не ломается.

## Что где править

- `src/data/phrases.js` — 20 фраз для мини-игры (текст + тип: характер / дружба / год / шутка)
- `src/components/Hero.jsx` — первый экран, имя, цифра 16, подпись
- `src/components/Game.jsx` — мини-игра «лови приятные слова» (сверху файла константы раунда: длительность, скорость падения, интервал появления)
- `src/components/Reveal.jsx` — пошаговое раскрытие после игры (тайминги шагов — `STEP_DELAYS`)
- `src/components/Gallery.jsx` — массив `PHOTOS` (количество фото и подписи)
- `src/components/Gift.jsx` — тексты подарка и шуточные характеристики клавиатуры
- `src/components/Footer.jsx` — финальное поздравление
- `src/styles/global.css` — токены дизайна: цвета, акцент (`--accent`), шрифты, отступы

## Особенности

- тёмная графитовая тема, один акцентный цвет, шрифты Geologica + Manrope (Google Fonts)
- мини-игра: слот двигается мышью, пальцем (touch) и стрелками ← →
- пропущенные слова не считаются ошибкой; можно пропустить игру целиком
- поддержка `prefers-reduced-motion` — фоновые анимации, конфетти и частицы отключаются
- адаптив: мобилка и десктоп
